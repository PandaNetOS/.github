## Hi there 👋
# PandaNetOS 🏗️
> 分布式媒体资源调度中枢

面向家庭私有NAS的分布式媒体资源调度中枢，统一接管下载、任务编排、媒体后处理、第三方系统互联。

- **pk(Core)**：编排内核，负责任务管理、定时调度、Vue3‑WebUI
- **spde(SPDE‑Worker)**：下载执行引擎，专注下载、种子清理、音视频后处理

📦 Repositories：https://github.com/PandaNetOS
📋 Roadmap：组织内 Project 看板
